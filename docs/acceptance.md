# 验收与演示步骤

1. 首页搜索餐厅或菜名，切换分类和排序；第二页可访问其余商家。
2. 游客收藏商家，跨页切换“只看收藏”，确认只显示收藏结果。
3. 注册一个新账号（用户名 3–20 字，密码 8–72 字），登录后查看本地收藏已合并。
4. 打开餐厅详情发布点评；个人中心编辑该点评并查看公开评分变化。
5. 用第二个普通账号尝试访问第一条点评的编辑地址，确认返回 403。
6. 管理员进入后台，新增餐厅、添加及编辑菜品；到用户端查看结果。
7. 后台隐藏、恢复点评，核对前台的数量和评分；查看操作日志。
8. 打开两个独立浏览器会话登录同一账号，修改密码后确认两个会话均需重新登录。
9. 使用 CLI 备份数据库；保留备份。恢复时先停止服务，再将所选备份复制到目标数据库路径。

自动验证：`python -m unittest discover -s tests -v`。测试使用临时数据库，不会修改工作区业务数据。测试覆盖角色权限、CSRF、收藏、评论归属、旧库迁移、备份、密码失效、登录限流、菜品管理与操作日志。
